# 📈 AlphaMind AI — کرپٹو سگنل ڈیش بورڈ اور اے آئی انجن

الفا مائنڈ (AlphaMind) ایک جدید اور خود کار کرپٹو ٹریڈنگ ڈیش بورڈ ہے جو مارکیٹ کے حالات اور لائیو کینڈل پیٹرنز کا تجزیہ کرتا ہے۔ یہ سسٹم **Google Gemini AI** اور **Binance API** کے ذریعے لائیو مارکیٹ سگنلز (انٹری پوائنٹ، اسٹاپ لاس، اور 4 ٹیک پرافٹ لیولز) فوری طور پر تیار کرتا ہے۔

---

## 🌟 اہم خصوصیات (Key Features)

- **لائیو مارکیٹ ریٹس:** بائننس کی طرف سے بٹ کوائن اور دیگر کرپٹو کوائنز کے ریئل ٹائم ریٹس۔
- **خودکار اے آئی سگنلز:** لانگ (LONG) یا شارٹ (SHORT) کے واضح سگنلز، رسک لیول اور کانفیڈنس اسکور کے ساتھ۔
- **دو بانی زبانیں (اردو اور انگریزی):** سگنل کی مکمل تفصیلات اردو اور انگریزی دونوں زبانوں میں دستیاب ہیں۔
- **ٹیکنیکل انڈیکیٹرز:** آر ایس آئی (RSI)، میک ڈی (MACD)، اور ای ایم اے (EMA) کا مکمل تجزیہ۔
- **ڈارک موڈ ڈیزائن:** ٹریڈرز کے لیے آسان اور دلکش انٹرفیس۔

---

## 🛠️ استعمال شدہ ٹیکنالوجیز (Tech Stack)

- **فرنٹ اینڈ:** HTML5, CSS3, JavaScript (ES6+)
- **اے آئی سروس:** Google Gemini API (`gemini-2.0-flash`)
- **ڈیٹا پرووائیڈر:** Binance REST & WebSocket API
- **بیک اینڈ سروس:** [AlphaMind FastAPI Backend](https://github.com/AnsarAbbas789/alphamind-backend)
